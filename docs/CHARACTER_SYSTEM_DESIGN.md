**5个心理学问题**:

| # | 问题 | 选项 |
|---|------|------|
| 1 | 当遇到压力时，TA通常会... | A.独自消化 B.向人倾诉 C.转移注意 D.直接解决 |
| 2 | 在社交场合中，TA倾向于... | A.保持观察 B.主动交流 C.小圈子深入 D.看心情 |
| 3 | 做决定时，TA更依赖... | A.逻辑分析 B.直觉感受 C.他人建议 D.过往经验 |
| 4 | 面对冲突时，TA通常会... | A.回避退让 B.直面解决 C.寻求调解 D.冷战处理 |
| 5 | TA最看重的关系价值是... | A.深度理解 B.共同兴趣 C.互相支持 D.自由空间 |

**计分逻辑**:
- 每个选项对应性格维度（内向/外向、理性/感性、独立/依赖、直接/回避）
- 根据选择生成初始 `CharacterProfile`
- 结果影响后续AI对话风格

## 3. 数据流设计

### 3.1 创建流程状态机

```typescript
// 创建流程状态
type CreateStep = 
  | 'personality-test'    // 心理学测试
  | 'profile-setup'       // 名称+头像+文件
  | 'node-calibration'    // 节点确认
  | 'success';            // 创建成功

interface CreateFlowState {
  // 当前步骤
  step: CreateStep;
  stepIndex: number;      // 1/5, 2/3, 3/3
  
  // Step 1: 心理学测试
  personalityAnswers: {
    questionId: string;
    answer: string;       // A/B/C/D
  }[];
  personalityProfile: Partial<CharacterProfile> | null;
  
  // Step 2: 基础设定
  name: string;
  avatar: string;         // emoji或图片URL
  uploadedFile: File | null;
  extractedText: string;
  
  // Step 3: 节点提取
  draftNodes: DraftNode[];
  characterBase: CharacterBase | null;
  
  // 操作
  nextStep: () => void;
  prevStep: () => void;
  setAnswer: (qId: string, answer: string) => void;
  setName: (name: string) => void;
  setAvatar: (avatar: string) => void;
  setFile: (file: File) => void;
  setDraftNodes: (nodes: DraftNode[]) => void;
  submit: () => Promise<void>;
  reset: () => void;
}
```

  }

  useCharacterStore.getState().setCurrentCharacter(character.id);
